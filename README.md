# ノベルゲームメーカー

テキストベースのノベルゲームを作るためのツールです。インストールは不要で、ブラウザ（Chrome / Edge 推奨）で動きます。
作ったゲームは **Windows用のEXE** または **HTMLファイル** として出力できます。

## 使い方

1. このフォルダ（`editor.html` と `runtime` フォルダ）をまとめてPCに置き、`editor.html` をダブルクリックします。
   - EXE出力には `runtime/player-stub.js` が必要です。`editor.html` だけを別の場所へコピーしないでください。
2. 左の「シーン一覧」でシーンを選び、右側で編集します。
   - **① 表示するテキスト**：名前欄（空欄なら地の文）と文章を入力します。「まとめて追加…」を使うと、
     `ユウキ：こんにちは` や `アオイ「やあ」` の形式で複数行を一度に追加できます。
   - **② テキストを読み終わったら**：次のどれかを選びます。
     - 次のシーンへ進む
     - 選択肢で分岐する（選択肢ごとに移動先シーンを指定。「＋ 新しいシーンを作って移動先にする」も使えます）
     - エンディング（エンディング名を付けられます）
3. 「▶ テストプレイ」でその場で遊んで確認できます（シーンごとの「このシーンから再生」も可能）。
4. 「⬇ ゲームを出力」から出力形式を選びます。

## 出力形式

### Windows用 EXE（販売・配布向け）

次の3つのファイルをまとめたZIPが作られます。

```
ゲーム名/
├── ゲーム名.exe                   … ゲーム本体（これ1つで起動）
├── はじめにお読みください.txt     … 起動方法・操作方法・動作環境・お問い合わせ先
└── THIRD_PARTY_LICENSES.txt       … 使用しているオープンソースのライセンス表記
```

- 対応OS：Windows 10 / 11（64bit）。Microsoft Edge WebView2 ランタイムを使います（Windows 10/11 には通常入っています。
  入っていない場合は、起動時にインストール先を案内するメッセージが出ます）。
- 「⚙ 設定」で次の項目を設定できます。
  - **アイコン**：EXEファイルとウィンドウのアイコン（PNG / JPEG。256×256 に自動で変換されます）
  - **ウィンドウの初期サイズ**：1280×720 など。画面のDPIに合わせて自動で拡大されます
  - **バージョン・お問い合わせ先**：「はじめにお読みください.txt」に書き込まれます
- ゲーム内の機能：セーブ／ロード（6枠）、全画面表示（F11 または画面右上のボタン）、ゲーム終了ボタン
- セーブデータの保存先：`%APPDATA%\NovelGames\<ゲーム名>_<ID>\`
- 右クリックメニューや開発者ツールは無効になっています。

#### 販売・配布するときの注意

- 出力したEXEにはデジタル署名がないため、初めて起動するときに Windows の SmartScreen
  （「WindowsによってPCが保護されました」）が表示されることがあります。「詳細情報」→「実行」で起動できます
  （この案内は「はじめにお読みください.txt」にも書かれています）。表示されないようにするには、コード署名証明書で署名する必要があります。
- セキュリティソフトによっては、まれに誤検知されることがあります。販売前に、手元のWindowsで実際に展開・起動して確認してください。
- 販売サイトの登録規約（ファイル形式・同梱物など）は、各サイトの最新の案内に従ってください。

### HTMLファイル

1つのHTMLファイルに出力します。ダブルクリックするとブラウザで遊べます（Mac・スマホでも可）。体験版の配布やWeb公開に向いています。

## プロジェクトの保存

- 編集内容はブラウザに自動保存されます。
- 「プロジェクト保存」（Ctrl+S）で `.novel.json` ファイルとして保存し、「開く」で再編集できます。
  別のPCに移すときやバックアップにはこちらを使ってください。

## 開発者向け：EXEランタイムの再ビルド

`player/` に Windows 用ランタイム（Go + WebView2）のソースがあります。Go 1.24 以降と Node.js があれば、Linux / Mac / Windows のどれでもビルドできます。

```sh
cd player
./build.sh     # テスト → novel-player.exe のビルド → ../runtime/player-stub.js を生成
```

EXE出力の仕組み：エディタは `novel-player.exe` の末尾にゲームデータ（HTML と設定）を付け足し、
EXE内の固定サイズのアイコン枠を利用者の画像に差し替えます。ランタイムは起動時に自分自身の末尾からゲームデータを読み込み、
WebView2 のウィンドウで表示します。
