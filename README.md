# ノベルゲームメーカー

テキストベースのノベルゲームを作るためのツールです。インストールは要りません。

## 使い方

1. `editor.html` をダブルクリックしてブラウザ（Chrome / Edge / Firefox など）で開きます。
2. 左の「シーン一覧」でシーンを選び、右側で編集します。
   - **① 表示するテキスト**：名前欄（空欄なら地の文）と文章を入力します。「まとめて追加…」を使うと、
     `ユウキ：こんにちは` や `アオイ「やあ」` の形式で複数行を一度に追加できます。
   - **② テキストを読み終わったら**：次のどれかを選びます。
     - 次のシーンへ進む
     - 選択肢で分岐する（選択肢ごとに移動先シーンを指定。「＋ 新しいシーンを作って移動先にする」も使えます）
     - エンディング（エンディング名を付けられます）
3. 「▶ テストプレイ」でその場で遊んで確認できます（シーンごとの「このシーンから再生」も可能）。
4. 「⬇ ゲームを出力」を押すと、ゲーム本体が **1つのHTMLファイル** としてダウンロードされます。

## 出力したゲームの起動方法

出力された `ゲーム名.html` をPCでダブルクリックするだけで、ブラウザでゲームが起動します。
インターネット接続や追加ソフトは不要で、ファイルを人に渡せばそのまま遊んでもらえます。

- クリック / Enter / スペース：文章を進める（表示途中なら全文表示）
- セーブ / ロード：ブラウザに1枠保存（タイトル画面の「つづきから」でも再開可能）

## プロジェクトの保存

- 編集内容はブラウザに自動保存されます。
- 「プロジェクト保存」（Ctrl+S）で `.novel.json` ファイルとして保存し、「開く」で再編集できます。
  別のPCに移すときやバックアップにはこちらを使ってください。
- 「⚙ 設定」で作者名、文字の表示速度、背景色・文字色・アクセント色を変更できます。シーンごとの背景色も設定できます。
